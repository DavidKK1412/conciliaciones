Unificar conciliaciones

Formato de conciliación → Libro auxiliar → Extracto, un PDF por cuenta. Todo se procesa en este computador: no se envía nada a internet.

1

Formatos de conciliación en PDF (Excel)

Una macro que guarda cada hoja _XXXX del libro de conciliaciones directo como MM_XXXX.pdf. Reemplaza separar las hojas y guardarlas como PDF una por una.

Ver la macro e instrucciones
  1. En Excel, con el libro de conciliaciones abierto: Alt + F11 → menú Insertar → Módulo.
  2. Pega el código y cierra el editor.
  3. Alt + F8 → ExportarConciliacionesPDF → Ejecutar. Te pide el mes y la carpeta donde guardar.

Usa el área de impresión que ya tiene cada hoja, así que el PDF sale igual que cuando lo guardas a mano. Si una hoja no empieza por "_", no se exporta.
